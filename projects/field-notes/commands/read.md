---
name: read
description: Read recent journal entries. Use when resuming work, checking what was done recently, or reviewing a specific session's history.
---

Invoke the `field-notes:read` skill using the Skill tool. If the user provided arguments, pass them as the `args` parameter.

Examples:
- `/field-notes:read` — show last 5 entries
- `/field-notes:read 10` — show last 10 entries
- `/field-notes:read today` — entries from today
- `/field-notes:read search SSE` — keyword search
